## 2차 변경과 검토 기준

기존 파서는 검색 결과를 20개에서 잘라 반환했고 번호 연결에 사용하는 `data-search-chunks`는 읽지 않았습니다. 예를 들어 `[1]`이 `referenceChunks.num: 1`을 통해 검색 결과의 23번째 URL을 가리키면 기존 응답에는 해당 URL이 없었습니다. 새 파서는 `[1]`과 `((1))` 표기를 청크 번호와 연결한 뒤 URL을 검색 결과에도 대조합니다. 확인된 링크를 본문과 `citations`에 함께 반환하며, 20개 제한은 인용하지 않은 검색 결과 보완에만 사용합니다. [Liner Search Agent SSE](https://liner.com/developers/docs/search-agent-api)

빈 링크, 알려진 예시 링크, 검색 결과에 없는 URL, 누락되거나 충돌하는 번호는 본문에서 연결 실패 표시로 바뀝니다. 원문을 가리키는 인용이 없거나 일부 연결에 실패하면 `sourceMissing: true`와 검토 문구를 반환합니다. 출처 목록에는 실제 검색 응답에 들어온 URL만 넣습니다. 출처 페이지의 접속 가능성과 각 주장에 대한 실질적 뒷받침은 자동 확인하지 않습니다. 인용 구문과 예시 도메인 검사는 대표 형식을 처리하며 임의의 HTML이나 복잡한 Markdown, 모든 가짜 주소를 판별하지는 못합니다.

영양교육은 한국어 문장과 적용 대상 확인을 요청하고 문서명 연도·발행일·시행일을 구분하도록 했습니다. 학교급이나 학년 정보가 없으면 특정 영양기준 수치를 제시하지 않도록 합니다. 운영 보고서에는 번호 대신 서버에서 매핑한 알레르기 항목명과 원래 집계값을 넣습니다. 자동 점검은 대표 표현, 인원수 누락·추가, 일부 항목과 수치의 연결 오류, 외국어 문장, 빈 링크와 예시 링크를 탐지합니다. 짧은 외국어와 간접적인 안전 보장, 다른 문장 구조에서의 집계 오류는 놓칠 수 있습니다. 영양교육에서 출처 적용 범위를 검토할 때 참고할 수 있습니다. [국가법령정보센터 학교급식법 시행규칙과 별표 3](https://law.go.kr/lsInfoP.do?efYd=20210630&lsiSeq=233553)

## 실행

```sh
npm run quality:liner
node tools/liner-quality.mjs 5
```

기본 모드는 주입된 가짜 `fetch`로 동일한 합성 Router JSON과 Search SSE를 반환합니다. 테스트는 두 프롬프트가 서로 다르면서도 모델 옵션과 입력은 동일하게 쓰는지, 합성 정상 응답을 처리하는지, 의도적으로 작성한 오류 예시를 품질 점검이 감지하는지 확인합니다. 측정값에는 공급자 응답 전체를 읽고 파싱하는 시간까지 들어갑니다. 각 측정은 새 서비스 인스턴스를 사용하고, 반복마다 A/B 순서를 바꿉니다.

실계정 비교가 승인되면 `LINER_API_KEY`를 로컬 환경 변수에 설정한 뒤 `node tools/liner-quality.mjs --live 5`를 실행합니다. 키는 명령 인자에 넣지 않습니다. `1`~`5`쌍을 선택할 수 있고, 한 쌍당 합성 입력 4건을 A/B 각각 한 번씩 보내 최대 8회 호출합니다. 도구는 호출 간격을 두고 재시도 없이 요청합니다. 각 행에서 응답 본문, 출처, 점검 코드, 응답 시간과 실제 외부 호출 시도 수를 확인할 수 있습니다. 결과를 공유할 때는 입력이 합성 데이터여도 모델이 생성한 본문을 먼저 검토하세요.

실계정 평가에서는 문장 자연스러움과 업무 활용도를 같은 기준으로 A/B 각각 평가합니다. 영양교육·대체식은 핵심 주장별 원문을 열어 해당 문장이 실제로 뒷받침되는지 확인합니다. URL이 응답의 출처 배열에 들어 있다는 사실만으로 그 주장의 정확성이 입증되지는 않습니다. 운영 보고의 항목과 값 연결, 한글로 쓰인 수치, 우회적인 안전성 보장도 검토합니다.

## 2차 검증 결과

Node 22.16에서 빌드, 타입 검사, 전체 테스트 57개와 Mock 스모크가 통과했습니다. 합성 A/B는 기능별 5쌍씩 총 40건을 실행했고 외부 호출은 0회였습니다. Search 응답 20건은 연결 검사 통과 여부와 별도로 `claimSupport: "manual_review"`를 표시했습니다. 23개 출처와 역순으로 배정한 인용 번호를 넣어 20번째 이후 출처가 보존되는 것을 확인했습니다. 2차 실계정 호출은 수행하지 않았습니다.

## 1차 검증 기록

Node 22.16에서 기능별 A/B를 5쌍씩 실행했습니다. 모의 정상 응답 40건이 품질 점검을 통과했고, 각 실행에서 어댑터 1회와 외부 호출 0회를 기록했습니다. `npm run build`, `npm run check`, `npm test` 전체 54개와 Mock 스모크가 통과했습니다. 오류 예시에서는 메뉴 누락·변형, 미입력 수치, 대상 없는 400 kcal 일반화, 알레르기 안전 단정, 소수 인원 복원과 중복 합산, 본문 URL과 출처 목록 불일치를 감지했습니다.
