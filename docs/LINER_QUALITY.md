# Liner AI 초안 품질 검증

기존 프롬프트는 `23a8264`의 문구를 합성 입력 4건에 맞춰 고정했습니다. 개선 프롬프트는 현재 `LinerService`에서 생성합니다. 각 A/B 쌍은 입력과 공급자 요청 옵션을 공유합니다. 비교 도구가 A의 `messages`만 교체하며 앱에는 버전 선택 옵션을 추가하지 않았습니다.

| 기능 | 기존 요청 | 개선 요청과 출력 검토 항목 |
| --- | --- | --- |
| 월간 급식 소식 | 대표 메뉴가 포함된 일반 안내 한 문단 | 대표 메뉴 세 개의 원문 표기와 월을 모두 반영하는 가정통신문. 메뉴 나열을 넘어 자연스러운 문장과 가정에서 나눌 이야기 제안이 있는지, 미제공 날짜·영양량·재료·조리법이 들어갔는지 확인합니다. |
| 영양교육 | 일반 정보와 공신력 있는 출처 | 국내 공식 원문과 적용 대상·시행일을 확인하고 실천 방법을 제시합니다. 대상군이 없는 현재 API 요청에서 특정 열량을 제시하거나 유치원생 기준을 전체에 적용하는지 확인합니다. |
| 대체식 근거 | 일반 대체 정보, 학생별 판정 금지, 원재료·교차오염 별도 확인 | 대체 후보와 선택 이유, 확인 사항, 근거를 구분합니다. 원재료·복합원재료, 교차오염, 다른 알레르기 유발 식품을 모두 다루고 학생별 안전을 보장하는 표현이 있는지 확인합니다. |
| 운영 현황 보고 | 집계를 바탕으로 중립적인 한 문단. 소수 인원 추정 금지 | 집계값을 해당 항목에 연결하고 `3명 미만`을 유지합니다. 역산·중복 합산 또는 근거 없는 총원·비율·증감·원인을 만들었는지 확인합니다. |

영양교육과 대체식의 핵심 주장 옆에 직접 근거가 되는 문서 제목과 URL을 표시하도록 요청합니다. 영양교육에서 현행 기준을 검토할 때는 공표일과 시행일, 유치원·초등·중등 등 적용 대상의 차이를 확인합니다. [국가법령정보센터 학교급식법 시행규칙과 별표 3](https://law.go.kr/lsInfoP.do?efYd=20210630&lsiSeq=233553)

## 실행

```sh
npm run quality:liner
node tools/liner-quality.mjs 5
```

기본 모드는 주입된 가짜 `fetch`로 동일한 합성 Router JSON과 Search SSE를 반환합니다. 테스트는 두 프롬프트가 서로 다르면서도 모델 옵션과 입력은 동일하게 쓰는지, 합성 정상 응답을 처리하는지, 의도적으로 작성한 오류 예시를 품질 점검이 감지하는지 확인합니다. 측정값에는 공급자 응답 전체를 읽고 파싱하는 시간까지 들어갑니다. 각 측정은 새 서비스 인스턴스를 사용하고, 반복마다 A/B 순서를 바꿉니다.

실계정 비교가 승인되면 `LINER_API_KEY`를 로컬 환경 변수에 설정한 뒤 `node tools/liner-quality.mjs --live 5`를 실행합니다. 키는 명령 인자에 넣지 않습니다. `1`~`5`쌍을 선택할 수 있고, 한 쌍당 합성 입력 4건을 A/B 각각 한 번씩 보내 최대 8회 호출합니다. 도구는 호출 간격을 두고 재시도 없이 요청합니다. 각 행에서 응답 본문, 출처, 점검 코드, 응답 시간과 실제 외부 호출 시도 수를 확인할 수 있습니다. 결과를 공유할 때는 입력이 합성 데이터여도 모델이 생성한 본문을 먼저 검토하세요.

실계정 평가에서는 문장 자연스러움과 업무 활용도를 같은 기준으로 A/B 각각 평가합니다. 영양교육·대체식은 핵심 주장별 원문을 열어 해당 문장이 실제로 뒷받침되는지 확인합니다. URL이 응답의 출처 배열에 들어 있다는 사실만으로 그 주장의 정확성이 입증되지는 않습니다. 운영 보고의 항목과 값 연결, 한글로 쓰인 수치, 우회적인 안전성 보장도 검토합니다.

## 이번 검증 결과

Node 22.16에서 기능별 A/B를 5쌍씩 실행했습니다. 모의 정상 응답 40건이 품질 점검을 통과했고, 각 실행에서 어댑터 1회와 외부 호출 0회를 기록했습니다. `npm run build`, `npm run check`, `npm test` 전체 54개와 Mock 스모크가 통과했습니다. 오류 예시에서는 메뉴 누락·변형, 미입력 수치, 대상 없는 400 kcal 일반화, 알레르기 안전 단정, 소수 인원 복원과 중복 합산, 본문 URL과 출처 목록 불일치를 감지했습니다.
